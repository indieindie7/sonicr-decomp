# Sonic R (Sega Saturn, Travellers Tales / Sega 1997) decompile notes
Research only, non-commercial; racing reference for the Scorcher improvement work. Never publish game files, bins, decompiles or the Ghidra db. No leaked source.
GameHut (Jon Burton, TT) notes on Sonic R: Documents/Scorcher/video-notes.md lines ~19-37, ~99 (CPU split), ~192 (SCU DSP), ~215.

## Setup (10-13)
- Source: Downloads/Sonic-R_SEGA-Saturn_EN.zip (Europe, 21 tracks; Track 01 data 16188816 bytes, 02-21 CD audio not extracted).
- image/ = Track 01 .bin + .cue. cd/ = 81 files (13.7 MB) via Scorcher tools/isoextract.py <bin> cd 2352.
- IP.BIN: MK-81800 V1.000 1997-10-17, "SONIC R", area E, 1st read address 0x06004000 (header +0xf0), size field +0xe0 = 0x1800.
- One program: 0.BIN 230772 bytes, loads at 0x06004000. Most other files start "RNC" 02 (Rob Northen method 2 packed): MISC/TITLES, OPTIONS, OPTION2, RESULTS, CREDITS, ENDING, ICONS, TRACKn.BIN; per course dirs BEACH CITY FACTR CAVES CHAOS hold TRACKn(H).BIN, <c>HI/LO/VRM.BIN, n.ENV, AISTUFFn.BIN (22 KB AI data), LEVn.SFX, REPLAYn.SFX, character .HID (MSONIC, MILES, MKNUCK, MROBOT); PATH/PATH1-4.BIN; MISC/PLAYERS.BIN unpacked (590 KB). Packed files may hold overlay code: check after an RNC unpacker.
- Compiler: GCC with frame pointer (prologue 2fe6 6ef3 = mov.l r14,@-r15; mov r15,r14; 4f22 sts.l pr).
